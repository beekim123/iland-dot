# 晴贝小岛 · Web 试玩包

包含动态小岛、动物、三色魔法传送门，以及 3D 俯视角糖果炸弹无限模式。

## 启动
1. 完整解压 ZIP，保持所有文件在同一目录。
2. 安装 Python 3 后，在解压目录运行 `python3 serve.py`。
3. 浏览器打开 http://127.0.0.1:8071/ ，点击“进入小岛”。Mac 也可运行 `start.command`。
4. 结束时回到终端按 Ctrl+C。服务仅监听本机，不会公开到网络。

**不能双击 index.html 启动。** 游戏需要 HTTP 和 WebGL 2。推荐有硬件图形加速的桌面浏览器；如浏览器缺少 WebGL 2，页面会说明原因，不需要降低安全设置。Python 不存在时需先安装；8071 端口被占用时请先关闭之前的服务。

## 操作
- 小岛：拖动旋转视角、滚轮缩放、点击动物植物获得反馈。
- 粉色传送门进入糖果炸弹；青色和紫色传送门尚未开放。
- 小游戏：WASD / 方向键移动，空格放炸弹，Esc 暂停，房子图标返回小岛。
- 浏览器首次点击后开启声音；没有声音时可再点击游戏区域并检查静音图标。
- 分数数据隔离在小游戏目录，Web 存档依赖当前浏览器与站点数据；清缓存、隐私模式或更换端口可能导致存档不可用。

## 技术与验证范围
Godot 4.7.2 官方单线程 Web 模板、GL Compatibility / WebGL 2，Web 音频使用 Stream；无需 COOP/COEP 跨源隔离头。资源、声音和骨骼动画均保留，不含源工程、Blender 工程或导入缓存目录。

导出与 ZIP 完整性、资源清单可核验；本云端环境是否能实际进入 WebGL 2 游戏需另看验收记录，不将静态检查当作浏览器游玩通过。build-manifest.json 记录资源哈希，source-manifest.json 记录导出输入。
