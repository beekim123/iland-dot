# 四门海岛独立验收

测试由独立 QA 编写；生产实现位于 `godot/app`、`godot/hub`。所有运行使用隔离 XDG 用户目录，不碰玩家存档。

## 验收边界

- 从实际可启动池选择最多四个不同入口；0–3款不得补重复，未知/禁用/缺失场景不能混入。
- 同一会话玩完返回及重启保持组合；显式换一组且有候补时至少改变一款。统计展示覆盖，不把随机算法宣称为绝对公平。
- 存档结构、重复ID、未知ID、少量可用、配置改变及坏JSON恢复；不可修改其他模块数据。
- 固定门位在默认视角可见、可点、互不重叠；物体遮挡与真实鼠标press/release走实际Viewport输入，不直接调用点击函数代替。
- 真实五模块启动、重复启动拒绝、返回路径和目录导航保存、键鼠确认不穿透、退出清理无新增孤儿节点。
- 目录支持鼠标键盘、禁用状态、响应式布局、关闭恢复视角。真实图形截图和GPU/Web性能是独立门槛，headless通过不代替。

当前版本目标：Godot 4.7.2 stable。测试输出必须记录实际版本、失败日志和具体被测源码；最终完整聚合前不得拿单项通过称全部通过。

## 运行

`bash tools/qa/four_portal_hub/run.sh` 默认执行 rotation、catalog_input、pagination、host_lifecycle、paged_host；也可显式列出所需套件。每套180秒超时且独立XDG。最新结果见 RESULTS.md；旧失败证据不覆盖新通过日志。
