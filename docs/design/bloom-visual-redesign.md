## 独立视觉语言

| 项目 | 拟定规范 |
| --- | --- |
| 主身份 | 明亮的温室竞技，不是夜间霓虹街区、软糖乐园或奶油布偶花园 |
| 队伍色 | 钴蓝 `#2F62FF`、橘橙 `#FF8A1F`；用于装备与液体，不能覆盖动物种属毛色；不回用旧青绿与珊瑚队色 |
| 建筑基色 | 冷矿物白 `#DCE1E1`、石墨灰 `#252E38`；植物绿色只用于环境，并适当降饱和 |
| 造型 | 清晰的大体块、硬软有对比的轮廓、少量有目的的细节；避免球体叠球体及统一圆角 |
| 光照 | 日间侧上方主光与明确接地阴影；中间调明亮，保留队伍色；不靠满屏辉光遮掩细节 |
| 材质 | 哑光矿物建筑、涂装金属、技术织物与亮面液体分层；不要所有表面同样塑料光滑 |

配色是拟定起点，需在真实 Godot 输出中校准。环境不能用高饱和蓝橙大面积装饰，干扰玩家判断地面归属。

## 当前动物角色规范

- 首批四种为兔子、狐狸、水獭、浣熊，各自独立建模。约2.5–3头身，耳朵不计入头身高度；短肢、动物爪掌、明确吻部与尾巴，体态随种属变化。**不是人类身体换动物头**，不保留人类脸、发型、裸露人类小腿或长指手掌。
- 采用独立的清爽 Q 版竞技风：清楚体块、短毛质感、少量有目的的毛簇和活泼表情。不复用海岛野生动物、软糖或旧布偶模板；也不把四种动物变成同一圆球模板的耳朵变体。
- 装备为轻运动背带或短背心、紧凑液罐与喷射器。保持动物脸、爪、尾和主要毛色可见，不用厚人类服装包住身体。蓝橙仅为装备队色，不能盖过种属毛色；种属不默认绑定某一队。
- 储液罐可读为装有液体的容器，枪与爪的握持关系清楚；无漂浮、穿模或靠特效掩盖造型的问题。设备不能遮住耳朵、尾巴或核心轮廓。

| 种属 | 必须能读出的轮廓 | 毛色与差异重点 |
| --- | --- | --- |
| 兔子 | 长耳、短兔吻、小圆尾、短前爪与较大后爪 | 冷灰白主体与少量灰色；耳与后爪主导轮廓，不是小人戴兔耳 |
| 狐狸 | 尖吻、三角大耳、短爪、明显蓬松白尖尾 | 铁锈棕橙毛色、浅吻胸、深爪；毛色与高饱和队伍橘分开 |
| 水獭 | 圆短吻/须垫、小圆耳、柔长躯干、粗根渐尖尾 | 暖深棕短毛与浅吻喉；不能画成小熊或使用狐狸蓬松尾 |
| 浣熊 | 短尖吻、眼罩毛色、小圆三角耳、粗环纹尾 | 灰褐主体、深眼罩和爪、浅吻；体态比狐狸敦实 |

### 当前制作与验证顺序

先完成各模型并以清晰的三分之四近景核对脸/吻、爪肢和尾巴，再提供四种同台的统一光照、地面和尺度对比；发现明确问题即修，不等待每只单独取得用户许可。随后制作真实绑定、动画并直接进入现有游戏场景，使用实际运行的动物动作展示验证，不以静态离线图代替。

角色专项门槛：四种不看文字即可区分；全身是卡通动物而非人类替头；耳/吻/爪/尾/毛色符合各自造型；装备克制且两队可辨；模型握持、接地与面部表情合理。用户允许继续制作不等于每个模型、绑定或动画已经通过验收。

真实骨骼要求：Blender Armature、身体权重蒙皮、Godot `Skeleton3D`/`Skin`及新动画应实际存在且驱动身体，不以整件节点旋转或静态模型冒充。罐/喷射器可以刚性挂骨，但握持与枪口必须稳定；动作中保持短爪比例、脚底接地和种属姿态，尾巴/耳朵不能穿身或被设备遮没。先用一只动物建立可复核的绑定与动作路径，再覆盖四种；保留可编辑源和导出记录。

## 场景与液体规范保留但当前暂停

场景围绕“苗圃支架改造的竞技场”组织：浅色地面和花槽、石墨支撑柱、疏朗温室拱架、清晰的模块接头与少量悬垂植物。优先制作少量有细节的原创模块并组合，不用无差别堆叠原始立方体代替环境设计。图中宫殿式繁复高塔不是必做资产。

保持现有可玩地面、掩体碰撞与机器人通路。周边高处结构须在明确边界外，避免看似可走却不能到达；植物集中在边缘和花槽，不遮挡可计分地面。浅色可涂地面与深色非涂结构应容易区分，地砖接缝不能重新形成抢眼棋盘。

液体以连续、饱和的有机覆盖面为主，辅以鼓起边缘、窄高光、短厚液带和少量拉丝液滴。喷射、撞击与铺地须连贯。优先做到真实运动中的厚度与读数，不追求概念图的镜面水面、无限碎滴或照片级反射。可见覆盖仍必须来自现有权威计分数据；不能用额外装饰液迹误导归属。

花苞沿用已有放置、预警、反制与开花规则，以硬壳瓣片展开和低矮液浪形成独有视觉。没有获批的新技能。

## 紧凑竞技 HUD 规范保留但当前暂停

- 顶部中央使用窄覆盖率条和计时器；总占高约 6%–7%，优先用排版而不是大底板划分信息。
- 每队只表示两名角色。概念图每队四枚菱形不能照搬为 4 对 4。
- 局中不显示概念图左上角的大幅游戏标题；名称留在适当的入口或结果场景。
- 中央小准星；左下紧凑生命与水量信息；右下冲刺、花苞的图标、可用状态和冷却。概念图中的示例数字和键位不构成规则变更，实装必须匹配实际绑定与数据。
- 单色几何图标、清楚的中文无衬线字形与等宽数字；禁止奶油胶囊、厚软阴影、贴纸式装饰和演示文稿卡片墙。
- 仅在需要保证对比的区域使用薄半透明深色衬底；适配不同宽高比，不遮挡主要瞄准区域。
- 暂停和结算采用同一独立视觉体系，但保留既有继续、重开和回岛闭环。不得因概念图好看而移除必要状态反馈。
