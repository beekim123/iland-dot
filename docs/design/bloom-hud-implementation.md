# 独立竞技 HUD 实装说明

2026-10-27。依据用户认可的日光温室竞技方向，重写模块内 `ui/bloom_hud.gd` 与 `ui/bloom_icon.gd`；不复用海岛或旧奶油胶囊组件。产品名称仍为「绒芽争园 / Bloom Skirmish」，模块与存档 ID 未改。

## 视觉与信息层级

- 石墨半透明薄衬底、矿物白排版、钴蓝 `#2F62FF` 与橘橙 `#FF8A1F`。1px 边线、1px 角半径，无软厚阴影、卡片墙或贴纸花朵。
- 参考 1280×800：顶部中置 560×54 广播条，约占画高 6.75%。覆盖条直接反映权威覆盖率，未占地部分留空，不擅自归一到 100%。中心计时独立于三秒开局倒计时；末 30 秒以橙色强调。
- 每队恰好两枚状态徽记：蓝队菱形 / V，橙队六角 / 双横杠，颜色以外保留形状识别。玩家有下划线；退场角色变灰并加斜线。状态读取真实 `roster`。
- 局中无大标题。准星只有中心点及四根短线，命中敌人时转橙；角色生命条和花苞引信保留。
- 左下为生命与液量，低生命或低液量有橙色警示；低液量提示停火补液。右下为冲刺 / 花苞，标记实际 SPACE / 右键，显示精确冷却及就绪/退场状态。冷却进度从 `sim.gd` 的 3 秒 / 12 秒常量读取。
- 基础操作提示在实际开始后第 9–12 秒淡出；事件提示单独计时。首次进入显示短说明，点击场景通过既有明确输入捕获鼠标，不新增大厅或规则。
- 暂停和结果采用同一平直双列版式：左侧状态/比分，右侧操作。暂停提供继续、重新开始、回岛；结果提供再来一局、回岛。胜、负、平局明确区分。

## 输入与布局

- `pause_requested`、`exit_requested`、`restart_requested`、`audio_requested` 信号不变，`update_state(Dictionary)` 与 `show_toast()` 不变；旧 `green`/`coral` 数据键保留，不影响规则/存档。
- 全屏普通展示控件、世界标签和开始说明均 `MOUSE_FILTER_IGNORE`。暂停/结果遮罩阻断场景点击；按钮独立处理意图。
- 顶栏工具键不获取键盘焦点，避免点击声音/暂停后 SPACE 被按钮消费；暂停主操作可键盘导航，继续比赛时明确释放 UI 焦点。
- UI 以 1280×800 为参考缩放，但逻辑画布随视口扩展：顶部居中，资源贴左下，技能与工具贴右边，不把宽屏内容锁在中央旧画框。
- 字体保持模块自包含；数字通过 OpenType `tnum` 使用等宽数字。新中文字符由根任务统一更新现有 Noto Sans CJK SC 子集，不引入系统字体依赖。
