## 原创设定与画面

两支绒芽园丁队在 **风铃苗圃** 举行园艺争地比赛，以彩色花露争夺地面。主视觉是连续、湿润、边缘不规则的液体覆盖，而不是重复花纹方格或零散珠粒。角色是原创圆润绒毛园丁，同一基础造型配两套队伍识别：青绿圆叶队与珊瑚星瓣队。花毯同时使用不同纹样与颜色，不能仅依赖色相区分。

采用**第三人称透视追尾/肩后镜头**，玩家背部在下方近景，中心准星指向有纵深的战场；鼠标可环视与俯仰，不能再以高位正交镜头展示整张棋盘。相机接近掩体时安全收缩，不穿模；近景模型、喷壶/背包、掩体与远景具有真实体积、接地关系和阴影。原创模型、界面、音乐和音效放在模块内，不复制参考作品角色、武器、美术、音效或品牌。不含乌贼变身、潜墨/下潜等设定。

## 一局的完整闭环

1. 点击海岛 **第二扇青色传送门**，直接进入短倒计时，无大厅、选关或配装页。
2. **玩家 + 1 名机器人，对抗 2 名机器人**，进行 **180 秒** 的 2 对 2 花露争地。
3. 时间结束立即停止有效玩法，按双方占据的可计分地面面积结算，展示胜、负或平局及双方比例。
4. 结算页可 **再来一局** 或 **返回海岛**；局中可暂停、继续、重开、退出。
5. 回岛恢复同一岛屿实例、原镜头、传送门位置与先前音频状态；再进入新一局不携带旧弹丸、花苞或输入。

完整玩法的含义是上述闭环、机器人竞争、资源取舍、攻击/受击、战术能力与可靠结算均可用，而不是以关卡数量或联网功能充数。

## 操作与规则

| 内容 | 批准的规则 |
|---|---|
| 移动与瞄准 | WASD 相机相对移动，鼠标环视/俯仰，屏幕中心准星瞄准；不是鼠标点选地面。准星与喷口遮挡一致，镜头不能让喷射穿墙 |
| 主武器 | 一把花露喷壶；消耗有限水量喷出粘稠液团，具有高度/重力与地面、掩体、角色碰撞。朝天空射击不得偷偷压到地面；命中产生冠状飞溅/散滴，落地形成连贯湿润覆盖 |
| 回水 | 停火后逐步恢复，不能无限连续喷射；水量和恢复状态可读 |
| 冲刺 | 短距离机动，不能穿墙，也不是无敌技能；有可读的冷却或可用状态 |
| 萌芽花苞 | 仅在己方花毯放置；约 3 秒明显膨胀/闪烁预警后，一次性把周围有效地面转为己方花毯 |
| 花苞反制 | 对方可在开花前击毁；每位角色同时最多一枚；不无限生长、不永久扩散 |
| 击败与复活 | 生命值归零后短暂退场，约 4 秒在本队保护区复活；击败不直接加争地分 |
| 争地胜负 | 唯一胜负依据是结束时的有效地面归属；可见液迹与计分来自同一份高分辨率权威数据，不用美术边缘掩盖判定偏差。对方可反复覆盖；障碍、地图外与受保护出生区不计分 |
| 机器人 | 三名机器人实际移动、涂地、争夺与交战，不以随机染色或后台加分代替角色行动 |

鼠标捕获必须在明确点击中发生；Esc、失焦、结算、退出释放指针，恢复按主动点击重新获取，不困住指针或误射。浏览器捕获须遵守实际输入事件限制。按键细分、伤害/射程/水量/冷却等为实现调参，不改变核心约束；最终操作须以修订后的模块 README 与屏幕提示为准，不能沿用旧俯视说明。

## 唯一地图：风铃苗圃

一张对称、主要行动地面为单层的紧凑竞技花园；这是玩法拓扑，不是俯视镜头或二维弹道。中央开阔争夺区，两侧各有侧翼通路；陶盆、木箱、矮花槽构成掩体，既可阻挡射击也提供绕行。出生区对双方公平并提供复活保护。不得出现角色能进入、机器人无法到达或无法染色却计入总分的地块。

通过中心压制与侧翼补地形成选择；立体掩体与远景温室提供第三人称深度和方向感，不用额外关卡或随机地牢代替当前地图的完整玩法。

## 信息、声音与反馈

- 顶部紧凑显示时间和双方覆盖率；血量靠近角色，底部显示水量、冲刺与花苞状态，避免遮挡主战场。
- 区分喷射、缺水、受击、击败、复活、花苞倒计时/开花、最后阶段与结果反馈。
- 队色以外保留圆叶/星瓣纹样或形状提示；角色朝向、中心准星、喷射落点、危险花苞位置可读；连续液团、碰撞飞溅和湿润覆盖必须在实际动态画面里可辨。

## 工程与独立性

- ID：`bloom_skirmish`；所有运行资源位于 `godot/modules/bloom_skirmish/`。
- 入口：`main.tscn`；宿主协议：`signal exit_requested` 与 `start(context: Dictionary = {})`。
- 固定存档命名空间：`user://games/bloom_skirmish/profile.json`，格式版本独立管理；不信任传入路径，不覆盖软糖游戏或海岛存档。未知未来格式不得由旧版本静默覆盖。
- 可独立运行并通过 `tools/extract_game.py bloom_skirmish <新目录>` 抽离；不依赖海岛脚本、其他模块、宿主 Autoload 或外部字体。资产来源、制作记录和许可证必须一并携带。
- 保持第一扇粉色软糖门和未开放门不变；第二扇门保留既有随机安全槽位、青色外观与同一回岛镜头行为。
