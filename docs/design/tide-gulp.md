# 第三款 · 逐潮小鱼 / Tide Gulp

**模块：`tide_gulp`｜状态：已批准，完整实现中；不是已完成或已验收。** 当前唯一在制作的新游戏。完成、验证并交付后，自动转入《鹈鹕急送》。顺序与完成门槛见[开发队列](../project/DEVELOPMENT-QUEUE.md)。以下数值是初始调参目标，不是实测结论。

## 核心体验与独立美术

从小鱼逐渐长大，在连续海域里判断可吞食对象、绕开天敌、利用流潮探索下一片生态。采用**独立水彩儿童绘本**：柔和纸感、色块晕染、可辨识鱼形与轻巧绘本 UI；不继承糖果、竞技场，也不是珍珠亮面塑料。鱼与环境是真正 3D，玩法限制在 **XY 平面、2.5D 侧视**，不把平面贴图冒充建模。

交付规模为 1 种玩家鱼、6 种常规鱼、2 种天敌；浅礁、海藻、遗迹 3 种生态，12 个主要地形单元和 2 个过渡区。每种鱼有可辨识轮廓、真实骨链尾摆、嘴部与鳍部动作、转身衔接，而非整模左右摇晃。

## 操作与吞食规则

- 鼠标指向移动，左键冲刺；亦支持 WASD 移动、Space 冲刺。两套输入共享同一物理与冷却规则。
- 接近对象后自动以嘴部接触吞食，不增加额外攻击键；体长判定与视觉大小一致。
- 以玩家有效体长 `P`、对方有效体长 `F` 判定：`F <= 0.8P` 可食；`0.8P < F < 1.25P` 相近体型只推开；`F >= 1.25P` 是危险对象，必须先给嘴部攻击预警，实际命中才结束本局，不以全身一碰就判死。
- `F < 0.35P` 的微小对象不提供有效成长与主要得分，只可轻微缩短冲刺冷却，防止无限刷小鱼成为最优策略。
- 6 阶成长，目标体长从 1 到 3.05；各阶阈值经实测调参。地图连续，最大体型封顶但仍可游玩争取成绩；没有饥饿掉级、装备或养成属性。

## 海流、生态与公平性

每个目标 60 秒周期由 35 秒平稳、5 秒可读预告、20 秒流潮组成；玩家与所有鱼遵守同一海流规则。流潮影响路线但不能随机夺走操作。危险鱼需有屏外预警、有限追击距离与时长；开局安全区与离开保护衔接明确，不出现无预告贴脸击杀。

鱼池、活动范围、地图边界与同时活动数量均有上限。回访区域按有界补充规则恢复，不能瞬间刷满；食物供给保证各成长阶都有可达目标，不靠等待偶然刷新才能过关。体型变化不能把玩家卡进地形，转弯、边界和窄口都需验证。

## 一局闭环、数据与范围

直接入场 → 吞食/成长/避险 → 死亡 → 成绩与成长记录 → 重开或回岛。暂停、退出、重开安全释放输入/音频/实体；最高成绩与历史记录使用固定 `user://games/tide_gulp/`，带格式版本，不写其他游戏数据。当前不承诺跨退出恢复一条未结束鱼生。

范围不含联网、开放海洋、装备、饥饿、随机永久数值强化。独立 `main.tscn`、源码/原创模型/音频来源、可复现制作脚本、许可证和测试一起交付。计划替换第三门的旧 `reef_memory` 占位，不沿用旧 ID 或存档；**本设计提交不改注册表或开放入口**。
