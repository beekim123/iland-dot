# 项目路线图

当前版本：保留已验收的 Q 版海岛大厅与软糖迷宫，第二门原创「绒芽争园」正在根据用户反馈重做第三人称镜头与液体喷射/铺地表现，当前未完成、未发布。旧俯视版的通过记录已被本轮目标取代。先完成一张地图的一局闭环，不用联网、武器数量或关卡数量替代玩法完成度。

| 模块 ID | 名称 | 设计与核心玩法 | 状态 |
|---|---|---|---|
| gummy_bomber | 软糖爆爆岛 | 格子移动、糖果炸弹、十字爆炸/连锁、可破坏饼干墙、敌人与增强道具；无限波次、死亡重试、回岛 | 既有验收记录保留；本轮回归，不改变规则 |
| bloom_skirmish | 绒芽争园 | 第三人称肩后绒芽园丁、连续粘稠花露争地；玩家+机器人对2机器人，180秒；有限水量、冲刺、可击毁延时花苞；结算、重开、回岛 | 修订进行中；旧俯视通过记录仅为历史，须重跑规则/相机/输入/液体/实机/导出；替代第二门 snake 计划 |
| reef_memory | 珊瑚记忆 | 翻开贝壳配对海洋图案，增加图案与节奏；适合短时休闲 | 仅设计，锁定 |
| cloud_hop | 云朵跳跳 | Q 版动物在移动云台间跳跃，连续攀升与收集；失误后可重开 | 仅设计，锁定；不新增岛上门位 |

具体通过项和平台限制见[任务板](TASKBOARD.md)。第二门详细范围见[修订设计](../design/bloom-skirmish.md)与[官方参考研究](../research/bloom-third-person-liquid.md)。`snake` 是被替代的旧计划，不另建模块，不把旧 ID 路由到新游戏，也不复用其存档路径。

每个项目按 `godot/modules/<id>/` 独立管理，不改其他游戏存档。每个模块须交付独立启动、退出协议、自测、实机验收、美术与音频来源/许可记录。先完成当前完整单模块，再考虑下一扇门；设计、实现、无头测试、实机与发布分别记状态，不把其中一项冒充其余项。
