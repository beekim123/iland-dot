# 项目路线图

当前目标：可交互的 Q 版海岛大厅 + 一个可无限游玩的糖果迷宫游戏。

| 模块 ID | 名称 | 设计与核心玩法 | 状态 |
|---|---|---|---|
| gummy_bomber | 软糖爆爆岛 | 格子移动、糖果炸弹、十字爆炸/连锁、可破坏饼干墙、敌人与增强道具；无限波次、死亡重试、回岛 | 本轮实现与验收 |
| snake | 果冻贪吃蛇 | 收集水果让果冻队伍变长；经典网格转向、身体/边界碰撞、逐渐加速 | 仅设计，锁定 |
| reef_memory | 珊瑚记忆 | 翻开贝壳配对海洋图案，增加图案与节奏；适合短时休闲 | 仅设计，锁定 |
| cloud_hop | 云朵跳跳 | Q 版动物在移动云台间跳跃，连续攀升与收集；失误后可重开 | 仅设计，锁定 |

未来项目按 `godot/modules/<id>/` 新增，不改其他游戏存档。每个模块须交付独立启动、退出协议、自测、美术与音频许可清单。先做完整单模块，再开启下一扇门；不把未实现玩法标为完成。
