## 每款的共用完成门槛

1. 完整玩法与独立美术/UI，不以小样、概念图或前作换色充数；设计中的规模和数值是初始目标，实测后在本模块记录调整。
2. 直接独立启动、暂停/重试/结算/回岛等全部适用流程；有版本的固定 `user://games/<id>/`，不影响已有游戏存档。
3. 规则、资源、生命周期、宿主回归与**真正抽离工程**验证；实际原生玩法操作及骨骼/视觉证据，不以 headless 冒充实机。
4. 源码、必要原创资源、制作脚本、许可证与验收记录齐备；按用户授权逐步提交推送，最后核对远端 commit/tree 和实际 CI 状态。未完成制作时可推真实进度，但不能标作完整交付或启动下一款。
5. 如某目标平台、声音试听或设备性能未测，明确列出边界；旧包不冒充新版本。只有需要新权限、关键设计变化或无法继续的阻塞才上报，不重复询问已授权的正常开工。
