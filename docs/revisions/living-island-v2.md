# 活力海岛 v2

用户反馈（2026-10-26）：现有模型和动作死板，希望空中飞行、水中游动、更真实的海水动态及海鱼。

保留 Q 版造型和原有独立项目；升级行为与水面表现，不把写实要求解释为改成照片写实美术。

验收目标：
- 海鸥在空中持续飞行，方向随路径变化，翅膀有推进与滑翔，不仅原地摆动。
- 海龟在浅海游动，螃蟹在沙滩行走。
- 新建可编辑 Blender 鱼模型，鱼群在海水中可见并沿路径游动。
- 海水有连续波动、岸边泡沫及深浅层次，避免不透明水面遮住鱼。
- Godot 4.7.2 Compatibility 实机验证，无模型穿地、镜头裁切及过曝。
- 交付新的实机动图；不是由静态图片伪造运动。

并行制作：动物行为、水面材质、鱼建模与鱼群、运行整合。最终以实际运行画面验收；技术测试不代替视觉验收。

## 已完成与验收（2026-10-26）
- 海鸥真实环岛飞行，随路径转向/侧倾，肩关节扑翼；最终前倾32°并收腿，避免悬浮站姿。
- 海龟移入前景浅水，沿路线游动并划鳍；螃蟹横向移动并交替摆腿。
- 新增原创鱼 GLB/Blender 源，16条鱼分两群；初版均匀圆环排列被拒绝，最终改为跟随领鱼的松散错列队形，带轻微异步调整。
- 水面透明波动、流动高光、海岸浪花、海底焦散与深浅过渡；根据实机画面降低了过强亮斑。
- 父代理通过云端 CUA 启动真实 Godot 窗口，检查透明海水、动物/鱼可见性和最终飞行姿态；最终采集120张真实视口画面。另检查中段frame040/060和四时点联系图。
- 全部120帧的19个动物/鱼对象的网格包围盒投影检查：无越界；1280×800参考视口最小边缘余量2.47px（属于紧凑取景）。
- 最终无头检查通过：模型/场景初始化、飞行高度、动物真实位置位移、16条鱼水下位移、波浪统一时间、镜头/静音控制。导入AABB是动态场景启动时的模型范围，不再是第一版静态沙滩摆放断言。
