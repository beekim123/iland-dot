# 建模重做 v3

## 反馈
2026-10-26 用户认为虽然动态已有改进，但模型本身仍丑，要求重新优化建模。

## 决策
本轮优先造型，不继续用动态掩盖模型问题。旧版及已交付动态保留。新资源隔离在 art/v3，先提供真实 Blender 静态建模预览，先提供静态实模图给用户确认，本轮不接入 Godot。用户于 2026-10-26 明确要求“建模重做了先发我看看，不要着急接入 godot”，等待后续确认再决定接入。

## 视觉方向
- 轮廓：从平面同心圆沙盘改成有高差、海湾和局部岩壁的非对称海岛。
- 植物：棕榈羽状叶、宽叶植物和花丛形成有层次的组合，不再是整齐杆子加星形叶片。
- 动物：统一精修的 Q 版语言，连续有机体块、自然连接的颈部与肢体，减少球体拼装感。
- 材质：更清晰的翡翠绿、暖沙色、珊瑚色和海蓝，避免过曝、灰白和高对比拼片。
- 构图：有主次、有留白，植物和道具成组布置，动物近景可读。

## 交付与边界
可编辑 Blender 源文件、GLB、复现脚本、完整岛屿与动物近景实模渲染。此轮不增加玩法、不创建远端、不自动上传 Drive，不宣称静态预览即用户验收。

## 最新美术与反馈节奏
用户进一步明确“不要求真实感觉，要 Q 版”。细密羽状叶已过于写实，改成少量宽厚圆润的卡通叶片；模型材质采用简洁、饱满色块，不追求自然纹理。每个组件产生真实建模预览就立即发给用户，不等待整批完成；有未修问题明确标注。
