# 晴贝小岛 · 环境建模

本文件仅记录环境资产。所有几何由原创 Blender Python 建模脚本构建，无外部模型或图片素材。

- 源脚本：`art/scripts/build_environment.py`
- Blender 源文件：`art/blender/environment.blend`
- Godot glTF 2.0 二进制资产：`art/export/environment.glb`
- 首张实模渲染：`art/previews/environment_isometric.png`

## 造型
约 22 米宽的奶油色不规则沙岛，东南岸内凹形成小湾；薄荷绿草坡向岛后方升起。多层实体地形、浅水色带、分段浪花与远海短纹理几何构成水岸；全部使用不透明面，避免透明排序和重叠闪烁。西侧的小型木栈桥连接沙岸与浅海。

8 株弯曲椰树独立建模树干生长环、9 片叶簇和 3 颗椰果。花丛含奶白/珊瑚粉鸡蛋花、黄色花心，搭配圆灌木、热带阔叶、草簇、风化圆石。沙滩散布带放射状纹路的贝壳与分叉漂流木。前滩为动物留出开阔空间。

## 技术
Blender 4.3.2；建模坐标 XY 地面、Z 向上，海面约 Z=0。GLB 标准转换为 Y 向上，导出仅包含环境 mesh，不含摄影机或灯光。环境共用 17 个材质，按材质合并为静态网格，以降低 draw calls。没有借用 Godot 运行时基础体代替建模。

构图为 Blender `(18,-24,20)` 朝 `(0,0.4,1.2)` 的正交视角，1280×960 原生渲染，Cycles CPU，48 samples（当前 Blender 构建无 OpenImageDenoise，因此关闭降噪）。源文件保留柔光灯及摄影机。

## 复现
在项目根目录运行：
```sh
/usr/bin/blender -b -t 8 --python art/scripts/build_environment.py
```

建议动物位置（Blender 坐标，最终按脚底高度微调）：海龟 `(-2.2,-4.8,0.65)`；螃蟹 `(2.0,-6.1,0.50)`；海鸟 `(5.5,-3.7,0.62)`。这些都是开阔海滩，不与主要树干冲突。

## 验证结果
- 实际环境：16 个 mesh、25,187 顶点、23,545 多边形；17 色材质表中深海备用色未使用。
- 向下射线验证脚底位置：`(-2.2,-4.8,0.668614)`、`(2,-6.1,0.649625)`、`(5.5,-3.7,0.604097)`。
- 海平面扩大为 100×100 米，避免正交远景露出平面边缘。
- 首次降噪渲染检测出当前 Blender 编译版不支持 OpenImageDenoise；已关闭降噪并用 48 samples 原生 CPU 实际渲染成功。
