# 晴贝小岛 · 原创音乐

## 可用成品

- `audio/export/sunny_shell_island_loop.wav`：48 秒全新原创器乐循环；80 BPM、4/4、16 小节，C 大调。
- `audio/export/ocean_ambience_loop.wav`：48 秒独立、克制的合成海浪循环。
- `audio/export/sunny_shell_island_audition.wav`：15 秒试听，已混合下述建议音量，含短起音与末尾淡出，不用于循环。
- 所有文件：44,100 Hz、双声道、PCM16 WAV；两个循环各 2,116,800 帧。

乐器为程序化软木琴／钢鼓近似主旋律、尤克里里式拨弦分解和弦、温和正弦贝斯、轻手鼓与沙锤。前八小节呈示，后八小节作旋律变化；保留节奏留白，不用密集鼓组。海浪由连续周期频谱噪声与缓慢潮汐包络构成，不使用录音。

## Godot 接入

两条独立 AudioStreamPlayer，建议音乐 `volume_db = -3`、海浪 `volume_db = -12`。WAV 设置前向循环，起点 0、终点 2,116,800 帧，或在导入面板打开循环。试听文件仅预览，不要用作背景循环。请保留独立开关／音量，不必将海浪烘焙进音乐。

## 来源与复现

本项目现场新写旋律与配器，无《一副山谷》旋律／录音复用，无外部音乐、授权样本、人声或生成模型。`audio/source/compose.py` 保留完整音符编排、加法合成器、合成海浪、导出与数值检查；`audio/source/score.json` 是可机器读取的曲谱事件（MIDI 音高、拍点、时长、力度、声像）。

运行：`python audio/source/compose.py`（Python 3 + NumPy；制作环境 NumPy 2.3.5）。固定随机种子。已完整重跑一次，三个 WAV 的 SHA256 均逐字节相同。音符尾音和早期反射按循环长度环绕累加，不在曲尾截断；海浪频谱原生周期连续。独立解码读取已通过。
