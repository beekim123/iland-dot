# v5 最终实际窗口验收

日期：2026-10-26。工具：云端原生 Godot 4.7.2 Compatibility / llvmpipe 软件渲染；不是无头测试截图。

## 本轮实测通过
- 用户已认可的悬浮能量裂隙已替换旧圆牌/底座，粉/青/紫效果及柔阴影可见；没有地面魔法阵。
- 修正 QuadMesh 继承 PlaneMesh 导致贴地误伤能量面的问题，实际重启确认竖向形态，相关自动回归已加入。
- 点击未开放紫色门，仍留在海岛；点击粉色门直接进入软糖炸弹玩法，无选关。
- 最新70° 3D俯视、图标HUD正常显示；实际键盘移动与放置炸弹后可离开，炸弹按实时消失，角色仍存活。
- 点击小游戏 Home 图标返回海岛，HUD、传送门布局、镜头视图恢复，没有小游戏界面残留。
- 双鸟、海豚、缩小的海龟/螃蟹已可见；骨骼播放与数据隔离另有自动检查。
- 原海岛旋转/缩放与静音控件已有实机验证，最新路由和输入释放有20次自动循环检查。

## 自动验证与可拆分性
`tools/test_all.sh` 汇总场景、路由、入口、规则、低FPS计时、存档版本及独立模块检查。模块可经 `tools/extract_game.py gummy_bomber <新目录>` 抽离；独立导入/运行与退出释放通过。具体计数和边界见相关报告，不把自动通过当作视觉验收。

## 限制
- 此环境没有可听音频设备；音效/音乐的资源、非零采样、路由、静音与生命周期经过验证，没有声称主观试听。
- 云端软件渲染观察约4–10 FPS；低FPS下采用墙钟固定步，炸弹不再被减慢。此值不代表本机GPU性能；尚未做用户Mac实测。
- 只实现软糖炸弹无限模式；其他三个条目为规划元数据，其中两个显示为禁用入口。
- 私人用户参考图 `art/references/**` 排除出公共仓库。官方研究图片未作为游戏素材提交。
