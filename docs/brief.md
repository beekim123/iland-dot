# 晴贝小岛 · 独立 3D 小场景

用户要求：在 dot 云端使用建模软件制作 Q 版小岛，包含海滩、动物、植物，自主设计；独立目录；导入 Godot 实际运行；原创主题音乐；先发建模图，再发实机图。

方向：圆润、明亮、奶油沙滩与薄荷青海水，安静可爱的小型热带生态岛。主体为约 22 米宽的岛；海滩、浅水、草坡、礁石、椰树/灌木/花、海龟/螃蟹/海鸟。可增加小木桥、贝壳、漂流木等点缀，不做复杂玩法或复用《一副山谷》内容。

制作约定：Blender 4.3.2 实际保存 .blend、导出 GLB。Blender 坐标 Z 向上，海面 Z=0，地形中心 (0,0)，主要海滩在 Y<0。角色 GLB 以脚底为原点，前向 Blender -Y，统一真实尺度。Godot 4.7.2 负责镜头旋转/缩放、动物轻动作、海水/风动、音乐音量和可读操作提示。模型成品不靠 Godot 临时基础几何替代。

性能：优先流畅可看的精致小场景；整体面数控制在合理范围，共享材质，尽量合并静态装饰。保留建模源文件、生成脚本和实际渲染图；不把概念图或静态渲染当运行验收。

目录：art/ 保存 Blender 源与 GLB，audio/ 保存原创合成曲谱和 WAV，godot/ 保存独立可运行工程，docs/ 记录设计和验证。
