# 晴贝小岛 v3 — 造型重做与视觉审查

## 任务边界

用户反馈：动起来了，但模型本身不好看，需要重新优化建模。本轮先重做真实 Blender 几何并检查静态建模图，不把动画、海水特效或渲染滤镜当作造型改进。

## 对旧版实际画面的诊断

已检查 `art/previews/island_complete.png` 与 `art/previews/animals_studio.png`，不是仅凭脚本推测。

- **地形**：外缘、沙滩、草地基本同心，像几层扁平饼干；没有能主导剪影的地形高差或明确海湾。
- **植物**：棕榈高度、间距和冠幅近似，冠叶像放射形花瓣而不是羽状棕榈叶；树下是零散小球、花、草，缺少连成一组的体块。
- **角色**：头、身体、翅膀等主要依赖球体堆叠。海龟甲片像贴上的平面片，蟹钳像圆手套，海鸥形体接近企鹅而非鸟。
- **画面**：高环境填光与浅色材料共同削弱明暗层次；重复的小物件在争夺注意力，前景动物在总览里过小。

## 用户追加约束（优先于首轮方向）

- **先看模型，再决定 Godot**：用户明确说“建模重做了先发我看看，不要着急接入 godot”。本轮只建模与静态预览，不改运行工程。
- **逐项发图**：每个组件实际渲染完成即可由主线程先发送工作图，不等待全部拼装或完美抛光。
- **Q 版，不要真实感**：用户明确说“不要太真实了，我不要真实的感觉，要 q 版”。因此否决首轮过细的棕榈羽片；改成矮胖弯干、每侧约 5–7 对宽厚圆叶片、小而丰满的树冠，以及简化大块的叶丛。岩石/码头/角色同样采用圆润玩具或黏土微缩场景语言，而非自然主义细节。

## 本轮造型方向与验收标准

1. **明确主次**：后侧形成一个高的植物/地形主群，侧边是较低副群，前方留连续沙滩空地；不做一圈等高棕榈。
2. **地形先于装饰**：不对称的雕塑式岛体、可读的内凹海湾、圆钝有切面的礁石和有支撑的厚木码头。
3. **真实叶片轮廓**：棕榈羽片有独立叶轴、少量宽厚圆润的成对小叶和夸张弯曲；深浅绿是体块层次，不是粉白覆盖。
4. **一致的角色语言**：海龟曲面甲片和鳍肢；螃蟹有可读开口的蟹钳与分段腿；海鸥有大头短身、圆钝翼片、简洁楔形喙；统一眼神尺寸和高光尺度。
5. **克制的颜色/布景**：深绿、翡翠绿、珊瑚橙、暖沙色与青蓝海水形成对比；柔和阴影，但不能高曝光漂白。
6. **真实交付**：可编辑并嵌入全部源数据的 `.blend`、无外部依赖的 `.glb`、实际 Blender CPU 渲染；绝不用概念画替代模型。

## 组装与渲染约定

- `art/v3/assemble_scene.py` 追加各工作源文件，不覆写植物/地形/角色工作脚本。
- 最终文件：`art/v3/sunny_shell_island_v3.blend` 与 `art/v3/sunny_shell_island_v3.glb`。
- 总览：`art/v3/island_v3_overview.png`；角色近景：`art/v3/island_v3_friends.png`。
- 最终渲染：Cycles / CPU / 1600×1200 / 64 samples；当前 Blender 构建不支持 OIDN，明确关闭降噪。
- 使用安静的连续海平面交代场景，不使用碎片/粒子掩盖造型。渲染海平面、灯光和相机不导出到模型 GLB。
- 总览与近景必须分别检查植物/动物穿插、脚底悬空、海岸层穿帮、裁切、曝光和主体识别度。
