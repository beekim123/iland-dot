# 实际场景封面

这五张PNG来自 `captures-20261028-040059` 的真实Godot 4.7.2原生窗口，根任务已逐张查看。PNG直接复制、没有AI编辑、没有后处理或像素重绘。

每款正常 `start(seed=71423)`，等待真实运行帧和至少4.5秒，只隐藏专属HUD以用于封面。没有改镜头、模型、位置、规则状态，没有自动操作来伪装玩家游玩。不是“完整玩法已演示”或性能测试。

`native-capture-manifest.json` 保留原始完整记录、原始文件路径和SHA；`manifest.json` 映射生产图片与原始SHA，必须逐字节相同。原始运行日志保留本地、不随仓库发布；`capture-source.gd.txt` / `capture-runner.sh.txt` 是当时采集器。Dummy音频不代表主观试听通过。

旧棚拍清单仅保存在 `model-portrait-history.json` 作为替换历史。旧 `tools/render_covers.py` 生成的是棚拍，不可再直接覆盖本目录五张实际场景图片。新的真实截图应经过同样来源记录与人工查看后替换。

传送门的shader只做正常画面裁切/边缘效果，标签为“场景预览”。未有场景截图的新游戏仍显示明确“主题图标”。
