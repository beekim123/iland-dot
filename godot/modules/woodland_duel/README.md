# 林间牌局 / Woodland Duel

原创纸雕童话回合制卡牌小游戏。三套预组牌免费完整可用，不含付费抽卡或局外数值养成。

## 基本玩法

- 双方20生命，每套20张牌，场上最多4名随从，手牌上限8。
- 自己回合最大费用增长1，最多6，回合开始补满；剩余费用不继承。
- 先手初始3张牌，所有回合开始均抽1张（含首回合）；后手4张牌并获得一张「一缕晨光」，可以留在手中；使用时仅该回合额外加1费用，不增长最大费用。
- 随从登场后等待自己的下个回合才能攻击，每回合一次。攻击随从时双方同时受伤。
- 守护限制随从的攻击目标；法术和登场效果按卡面选择目标。
- 空牌库抽牌造成递增疲劳伤害。双方同时失去所有生命为平局。
- 最多60个双方交替回合，达到上限按剩余英雄生命判胜负，同生命平局。

三套牌各含10种卡、每种两张。林间野兽重守护、成长和恢复；发条玩具重直接伤害和进攻；蘑菇精灵重退场召唤和群体成长。卡面和游戏内规则提供具体说明。

## 隔离与抽离

入口为本目录 `main.tscn`。宿主只通过 `start(context)` 与 `exit_requested` 协作。设置和记录仅使用 `user://games/woodland_duel/`；模块不依赖其他小游戏的资源。

在仓库根目录运行 `python3 tools/extract_game.py woodland_duel /absolute/new/directory`，再用Godot 4.7.2打开输出的 `project.godot`。
