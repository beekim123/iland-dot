# 鹈鹕顺风车 · Pelican Pedal

2026-10-28 重新实现，不声称恢复丢失的旧源码。独立第一人称 3D 卡通自行车配送模块。

## 运行

Godot 4.7.2；打开宿主工程后直接运行 `res://modules/pelican_pedal/main.tscn`。首次导入 GLB、字体和音频，无需安装 Blender。仅本模块及一份 main_scene 指向上述场景的 project.godot 即可独立运行；不依赖海岛或其他小游戏。

- W/S 前进/倒车，A/D 转向；低速也需要移动才能转向，不是原地旋转角色。
- 空格刹车；停车且距离目的地2.5米内按 E 取件/交付。
- 按住鼠标右键环视，松开后渐渐回正；Esc 暂停并释放鼠标。
- 连续按 R 1.3 秒扶正到已实际到访的安全路点，不会传到下一个交付点；扣5点完好度。
- 暂停可关闭镜头轻微晃动，默认关闭；失焦自动暂停，不自动恢复。

## 完整回合

码头取货→依序交付2至3站→成绩→下一单，8种连通路网配送顺序循环，没有选关。第一单没有流动车，后续有两辆慢速路面小车。北部道路平滑上坡；建筑实体、外围护栏与数据碰撞一致，草地减速。HUD方位标和地面目的地圈提供导航。

碰撞降低包裹完好度，归零后可重新配送；超时仅失去100分准时奖励，不会突然失败。每站150分，剩余完好度每点1.5分，扶正额外扣10分。终局停止世界推进，结果不可重复累计。下一单为新状态；重新配送保留已完成总记录，不能刷同单重复得分。

## 存档与边界

固定 `user://games/pelican_pedal/profile.json`，含订单、位置、方向、货物、时间、已完成数、累计分与舒适模式。恢复时车辆安全停车，不保留按键。三秒自动保存，暂停和正常退出立即保存。临时文件原子替换与备份；坏文件、未来版本、外部修改和错误上下文禁止覆盖并显示警告。独立命名空间不会覆盖别的游戏。

## 资产与验收

art/ 为可复现模型与真实16骨骼蒙皮动作、自行车轮/脚踏同步；ui/ 字体单独OFL副本；audio/ 为AI辅助原创40秒乐曲及6个合成提示音，附生成器，未使用第三方采样。

tests/run.sh 在全新独立副本导入并运行合法驾驶、碰撞/超时/扶正、存储、运行时生命周期与资产测试；任何引擎错误或泄漏使任务失败。自动驾驶是普通指令验收，不是人工实机成绩。原生画面、鼠标捕获、真实窗口关闭、主观音频与Web/GPU性能需分别记录，不能以无头通过替代。

独立运行 `main.tscn` 时，“回到海岛”没有宿主可返回，因此保存后安全关闭进程；嵌入宿主运行则发出 `exit_requested` 由宿主返回海岛，不关闭宿主。暂停/结算两种按钮路径均有真实 Viewport 输入及进程退出回归测试。
