# Beach Cleanup interface

New independent AI-assisted code-drawn design: sand-colored bevelled beach signs, petrol-green stamped lettering and twelve physical cargo recesses. No older module interface/theme reused. Font only: self-contained Noto Sans CJK SC Regular subset, source `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`, face 2, upstream https://github.com/notofonts/noto-cjk; SIL OFL 1.1 in OFL.txt. Reproduce with `python3 subset_font.py` from repository root or any cwd.

HUD design coordinates 960×540, uniformly fitted with letterboxing to viewport. Interactive buttons use native Godot keyboard focus and visible cream focus outlines. Pause, return/replay confirmation, completion postcard share this design. Before/after images must be supplied by runtime from identical world camera.
