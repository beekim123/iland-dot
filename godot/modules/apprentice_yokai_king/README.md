# 见习小妖王

Godot 4.7.2。运行 main.tscn，或用仓库 tools/extract_game.py 抽离独立工程。

WASD 移动，鼠标操作，Space 闪避，Esc 暂停；完整说明以游戏内为准。

固定独立存档：`user://games/apprentice_yokai_king/`。宿主接口 `start(context)` 与 `exit_requested`；不依赖海岛或其他模块。

仅包含实际运行所需图像/音频、代码、运行manifest、测试与字体许可证；AI辅助原创插画，动画仍有润色事项，非全部最终人工视觉验收。制作原画、生成器和过程记录不在此runtime源码包内。
