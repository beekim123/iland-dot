# Jungle Sans Subset

Renamed simplified-Chinese subset of Noto Sans CJK SC Regular (TTC face index 2), from Debian fonts-noto-cjk `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`. Upstream https://github.com/notofonts/noto-cjk . Distributed under SIL Open Font License 1.1, complete Debian/upstream notices preserved in OFL-Noto-CJK.txt.

`python generate_subset.py` scans all module GDScript (including runtime and storage warnings), adds ASCII and interface punctuation, subsets with fontTools, and renames the modified font family. No OS font dependency at runtime. Rerun when adding new translated messages. Included glyph inventory: included_chars.txt. This font is not authored by us and is not CC0.
