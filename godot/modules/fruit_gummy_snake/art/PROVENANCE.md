# Fruit Chews art provenance
All mesh designs are original code-native Godot meshes authored with AI assistance in `gummy_art.gd`. No images, textures, animal meshes, or material system from Gummy Bomber were reused. Font: Noto Sans CJK, SIL OFL; exact local subset generator and license are included in ui/. Gummy appearance uses opaque glossy materials, cream highlights, pastel colors and squash/stretch; it does not claim physical subsurface transport. Collision always belongs to sim grid cells, never the deforming mesh. Models are self-contained and do not require Blender.

## Underwater XYZ revision — 2026-10-28
- `underwater_art.gd`: original procedural geometry written for this project; all source included. No downloaded art, fonts, textures, models, or external references. Existing original fruit generators are reused from this same module's `gummy_art.gd`; the old tray generator is not used.
- Runtime interface: `ocean()`, `snake()`, `update_snake(node, body:Array[Vector3], forward:Vector3, time:float)`, `fruit(kind)`. World Y up; head local forward -Z; body points ordered head to tail, recommended arc-length spacing .55 m.
- Continuous skin: 10-sided tapered tube, 2 samples per path interval. 120 input points = 239 rings / 2,390 vertices / 4,760 triangles. All head/fins/eyes are original sphere-derived meshes. Dynamic fins and tail; trajectory drives the skin (no bead chain).
- Gummy appearance is an opaque high-gloss/rim-light approximation, not actual volume refraction. This deliberately avoids alpha sorting failures on Compatibility/Web. Shafts alone use low-alpha transparent material.
- Environment: 7 instanced batches (sand, rocks, two coral colors, kelp, particles, corner depth markers), one floor, five low-poly light-shaft meshes; no gameplay collision geometry. Reef inside ±24 stays below playable Y=2. Tall outer reefs supply parallax without blocking swimming.
- Material colors tuned for LINEAR tonemapping, .85 exposure / .28 ambient / .55 sunlight baseline, not FILMIC/high exposure. Runtime owns camera, lights, fog, food positions, and collision.
- Validation: standalone Godot 4.7.2 headless generation smoke test creates ocean, 40-point curved tube (790 vertices), all five foods without script/runtime errors. Native visual verification remains separate.
- Reproducible geometry validation: Godot `--headless --path <project> --script res://modules/fruit_gummy_snake/art/validate_geometry.gd`. Maximum body generates 2,390 vertices / 4,760 triangles; all tested triangles clockwise relative to outward normals (0 reversed). Real animated model inspection: `res://modules/fruit_gummy_snake/art/underwater_preview.tscn`; this is explicitly a model-preview scene, not simulated gameplay.
